# Dashboard UX audit

Scope: the dashboard (all eight views), the popup and the shared components, as of 2026-10-20. Method: the screenshots the browser suites save in `.e2e-profile/artifacts/` (Chrome 155, dark theme, 800 px and 1280 px wide), filter-bar measurements in Chrome at 640 / 800 / 1000 / 1280 px, the UI component tests in `tests/ui/`, and reading the components. No user testing took place, and the DevTools panel was not reviewed visually (it can't be opened by automation).

Severity: **High** blocks or misleads a task, **Medium** slows it down or confuses, **Low** is polish.

## Verified as working

- **Empty states** distinguish "nothing captured yet" (with how to start) from "no request matches the filters" (with **Clear all filters**). Tested.
- **Active filters** are listed as removable chips with a live count ("2 of 4 requests", `aria-live="polite"`). Tested.
- **Large sessions:** the request list renders a fixed window of rows. 50,000 requests render in ~50 ms in jsdom with fewer than 40 row elements, and scrolling to the end shows the last row. Analysis over 2,000 requests and 20,000 messages stays under ~250 ms in total. Tested.
- **Keyboard:** `/`, `j` / `k`, Esc, Alt+1…8, Ctrl+K and `?` work. Single-key shortcuts are ignored while typing. The command palette supports arrows, Enter and Esc, and hides disabled commands. Tested (unit and browser suites).
- **Dialogs** move focus in, trap Tab / Shift+Tab, close on Esc and return focus to the opener. Destructive actions (delete selected, clear session) need confirmation. Tested.
- **Status is not color-only:** badges carry an icon and text, and evidence levels and link strengths are words ("Strong hypothesis", "by time only"). Tested for badges.
- **Theme:** follows the system by default; light and dark can be chosen in Settings, and the choice survives a reload. Without storage it lasts for the page. Dark tokens are identical for the explicit choice and the system preference. Tested.
- **Unconfigured features say so** instead of showing zero: the Overview's server-tracing tile reads "Not configured". Workspace stages that weren't recorded are labelled "Unknown" or "Not instrumented". Tested in the realtime browser suite.
- **Popup** at its real width shows the recording state. Tested in the realtime browser suite.
